AI Agents Master

Master working environment for building and running AI agents

About this environment

This project is a production-ready stack for multiple AI agents: FastAPI, async Postgres (local or Supabase), and Alembic migrations. Each agent lives under app/agents/<name>/ with its own router, service, and schemas.

How to start creating a specific agent

  1. Create a folder under app/agents/<agent_name>/ (e.g. app/agents/my_agent/).
  2. Add modules: __init__.py, router.py (FastAPI routes), service.py (business logic), and schemas.py (Pydantic request/response models).
  3. Register the router in app/api/v1/router.py: include your agent’s router with a prefix like /agents/<agent_name>.
  4. Implement the agent in the service layer (calls to LLMs, tools, or DB as needed). Keep the router thin and delegate to the service.
  5. Run the API with uvicorn app.main:app --reload and call your agent via the new routes (e.g. POST /api/v1/agents/my_agent/run).

Use the existing app/agents/example/ agent as a template: copy its structure and adapt router, schemas, and service for your use case.
